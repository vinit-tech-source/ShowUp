# Privacy Policy

## Overview

ShowUp is a **local-first** application. All your data stays on your machine.

## What Data ShowUp Processes

- **Booking records** you import from CSV files (client identifiers, appointment
  times, outcomes, optional service/price/channel information).
- **Scoring results** computed locally from your booking data.
- **Draft messages** generated by a local AI model (Gemma via Ollama).

## What ShowUp Does NOT Do

- ❌ Send any data to external servers or cloud services.
- ❌ Collect usage analytics or telemetry.
- ❌ Store or transmit real names, phone numbers, or email addresses in logs.
- ❌ Auto-send messages to your clients.
- ❌ Use age, gender, name, phone, or neighbourhood for risk scoring.

## Network Connections

ShowUp makes **zero outbound network calls**. The only network communication is
with a local Ollama server running on your machine at `localhost:11434` for
AI-powered message drafting.

## Data Storage

All data is stored locally in a single SQLite database file. The default location is:

- **Windows**: `%LOCALAPPDATA%\ShowUp\data\showup.db`
- **Linux/macOS**: `~/.showup/data/showup.db`

Database file permissions are restricted to the current user.

## Deleting Your Data

You can delete **all** ShowUp data (database, caches, logs, and model outputs)
from the Privacy page in the application. This action is irreversible.

## Logging

ShowUp uses structured logging with automatic PII redaction. Names, phone
numbers, email addresses, and message content are **never** written to log files.

## Third-Party Models

- **Gemma** (Google DeepMind): Runs locally via Ollama. No data is sent to Google.
- **TabPFN** (Prior Labs): Runs locally with downloaded weights. No data is sent
  to Prior Labs.
